# VALORANT ROLE ANALISIS

Website rekomendasi role pemain Valorant berbasis Machine Learning menggunakan algoritma K-Nearest Neighbors (KNN) dan Random Forest.

## Teknologi

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Scikit-learn
- Joblib

## Cara Menjalankan

1. Install requirements

pip install -r requirements.txt

2. Import database db_valorant.sql

3. Jalankan

python app.py
